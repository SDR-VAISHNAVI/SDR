SOFTWARE DEFINED RADIO

Computer Science Project

This project integrates multiple technologies to control an RC car, transmit FM signals, and capture calling bell frequencies using a Raspberry Pi, RTL-SDR, and PiFM. The platform is divided into three main functionalities: controlling the RC car through signal transmission, broadcasting FM audio via PiFM, and capturing the calling bell’s frequency using RTL-SDR for signal analysis. Each module works seamlessly together, demonstrating the potential of software-defined radio (SDR) and RF technology in real-world applications. The goal is to showcase the power of Raspberry Pi and SDR for controlling devices and transmitting signals efficiently in a networked environment.
